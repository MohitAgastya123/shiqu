## Decisions

- Create `feature/comic-composition-ack` from the current verified upload branch and reuse this checkout. Push this feature branch to origin after GC; this includes its existing upload-feature ancestry. Do not merge main, create a worktree, package an installer or publish user content.
- Add `lib/comic-composition.ts` as the shared normalized composition contract. A page may contain `composition:{canvas,focus:{x,y},protectedAreas:[{kind:'face'|'action',x,y,width,height}]}`. Coordinates must be finite, bounded and completely inside the image; cap areas at 12. Canvas values are `9:16`, `4:5`, `3:2`, `2:3`. The whole field is optional for historical pages; new generated-page JSON requires it. New normal/wide/large/splash scenes generally select 4:5/3:2/2:3/2:3. Cover all visible faces (including non-speakers) and decisive actions/props, while leaving modest natural clear space. These are planned staging instructions, not pixel-level face detection. No new paid vision stage or detector dependency.
- Preserve composition through current plan/draft/batch/repair/restructure/history/revision/source-view/export projections. Fresh planning/batch output and newly inserted structural frames require it. Ordinary repairs of legacy frames use an optional composition field: a caption-only repair must not invent geometry or change a legacy canvas. Application merging retains the saved composition when the scene prompt is unchanged, including when a provider omits it; a scene-changing repair accepts newly validated composition or conservative absence rather than retaining stale protection. Include canvas/focus/protected staging in actual image input comparison and prompt payloads; modifying this staging through an explicit revision invalidates corresponding art and anchor dependants, but not source review when narrative fields are unchanged. Continue excluding panel emphasis and balloon body geometry from editorial comparisons. A panel-only layout revision must still reuse art. Existing completed art is never redrawn merely because code is upgraded.
- Make image sizing depend on the explicit `composition.canvas`, not on a mutable presentation-only panel hint. Missing composition retains the existing 9:16 contract. Add shared canvas targets and directions: 9:16 at 864x1536, 4:5 at 1024x1280, 3:2 at 1536x1024 and 2:3 at 1024x1536. Gemini receives the corresponding aspectRatio; Codex receives matching native-size/staging directions; OpenAI receives a matching 16-pixel-aligned size. A valid explicit resolution override should retain a comparable pixel budget when retargeted to a new planned aspect; preserve exact old validation/behavior for legacy calls. Malformed/excessive overrides fail clearly; never stretch/pad returned art to counterfeit a ratio. Verify current provider contracts before implementation if local code cannot settle a supported size.
- Replace hardcoded lianhuanhua/portrait directions with one selected-style comic scene and explicit canvas/staging geometry. ACK uses original classic Indian adventure-comic visual language: expressive variable-weight ink contours, rich opaque flat colours, restrained shadows, detailed scenery and warm print character. Preserve the actual source's culture, era, ages and clothes; never force a modern kitten story into ancient Indian history. No baked lettering, panels, publisher logos or copied reference characters.
- Keep one shared panel presentation. It exposes the panel rectangle, full transformed artwork rectangle, clipping viewport, compact narration geometry and fitted balloons. Browser SVG clips the same transform that canvas uses. Fill the artwork viewport edge to edge without stretching. Allow a focal crop only when at least 65% of source area remains and protected regions remain fully visible with clearance. Try another complete ordered, aspect-aware template when a crop is unsafe. Historical raw images with no authoritative composition are wholly protected for cropping: do not infer a safe crop from a centre point or speaker halos. Semantic span hints guide the choice, but cannot force an extreme legacy portrait crop. Try aspect-matched templates, then a compact safe lettering band and promotion; a final full-scene contain result is allowed only after the finite filled candidates fail, not as the default for all portraits. Include a compact three-column/six-panel option for portrait-heavy saved stories if needed; partial final sheets may retain unused paper outside panels, rather than recreating empty matte inside a frame. Preserve the existing canonical map catalog when validating older archives; new maps must also use a finite known catalog and retain every frame once in reading order.
- New page geometry uses tight outer margins/gutters, compact caption strips and bounded signature reservation derived from the existing 12–48px watermark contract and its actual margins, rather than a blanket 88px. Preserve all author marks and their WebP hashes/XMP. Do not remove a signature or overlap it with narration. Keep long PDF titles, page numbers and credits outside the actual panels. The composition contract may carry the selected publication font through internal layout options so browser and all exporters agree.
- Use a final-sheet story-lettering floor of 20px on 900px pages, with ordinary balloon fitting targeted around 22px instead of 32px. Keep the bundled comic font and current oval/cloud rendering. Size bodies to their actual words; bound tails and thought trails and avoid drawing speaker labels. These values replace the earlier feature's 24px minimum for newly composed raw art; baked lettering must never be cropped or repainted. Preserve the previous 24px readable floor for legacy known baked records (minFontSize >= 24), rather than comparing every baked image against the new 20px raw-art floor. New exports declare a correct 20px lower bound and use that floor. A null/unknown baked minimum remains splash-only. Test an old 24px record whose scaled lettering would fall between 20px and 24px: it must promote or fail rather than pass under the new minimum.
- Extend automatic placement with normalized protected regions, a permitted body region and finite ranked search. Protect planned faces/actions and conservative head halos around original speaker targets. Exclude body/stroke and inappropriate connector intersections; clipped short tails should point toward the associated speaker rather than cross another subject. Prefer small bodies, short tails, clear space and established reading order. Bound candidates/search states so 80-frame stories remain usable; include all relevant inputs in the bounded presentation cache and return isolated results.

For legacy frames without reliable composition metadata, the whole image is a body-exclusion region and protected for crop; use an automatic external lettering band, not an overlay selected only from speaker halos. Conservative halos supplement this policy but cannot certify the location of silent characters or actions; do not claim actual face recognition from a tail point. Text is complete, bodies remain outside protected scene content and tails remain bounded. An impossible full-page density remains a clear numbered error, never truncation or invisible text. ## Rollback / Risk

Optional composition JSON is backward-readable and does not require a library migration. Older editors may drop new metadata, so document compatible-version editing. Generated protected regions can diverge from actual art; conservative placement/bands and actual visual inspection are required, and no pixel detector is claimed. Unsafe legacy aspect changes must adapt layout or preserve the scene instead of aggressively cropping. Dense lettering may require more/larger panels; never shrink below the floor. Baked old illustrations cannot be repaired from raster alone. Preserve signed public WebPs without re-encoding. Provider canvas changes must not invalidate or replay already-paid saved results, and explicit revision cost previews must match reuse. Temporary previews/exports stay local; only source/docs/synthetic verification assets are pushed.
