# 《孙悟空三借芭蕉扇》五模型生产对比

2026-11-05，同一段《西游记·路阻火焰山》原文、同一用户制作要求、适中详略、自动幅数，Gemini Flash、Gemini 4 Argon、Codex 已通过审片的结果分别为 **16、41、70 幅**；DeepSeek 与 Claude 分别保存 **50、67 幅待审稿**。

## 执行摘要：故事质量与采用结论

**就本篇已保存的稿件，Codex 是首选主稿，Gemini 4 Argon 是首选紧凑版。** Codex 的优势在于把人物为何拒绝、为何相信、如何受骗，以及胜负已定后为何仍须还扇交代清楚；Argon 用较短篇幅保住主线和关键过程。判断依据是原典忠实度、行动与反应的因果、静态画面的可执行性和结语的分寸，不是幅数或自审次数。

| 稿件 | 质量结论 | 决定性证据与局限 | 采用建议 |
| --- | --- | --- | --- |
| **Codex：70 幅，通过审片** | 本例中叙事与分镜完成度最高 | 主动受剑、冒名骗扇的信任变化、斩头无效与制服奏效、讨扇与履诺都有独立表达；结语有明确情节支点。部分问路、传话和往返仍可压缩。 | 作为完整连环画的编辑底稿，保留关键交锋，精简重复过场。 |
| **Gemini 4 Argon：41 幅，通过审片** | 较紧凑、过程较完整 | 相比 Flash 补出了求扇、化蟹潜潭与真假扇得失；降牛、灭火与还扇仍偏集中，部分过程依赖配文。 | 适合更短的阅读篇幅，也是检查 Codex 哪些过场可以合并的参照。 |

**编辑上的下一步是选稿、定向压缩和核实，而不是继续堆幅数或增加自审轮次。** 若要完整呈现本篇，以 Codex 稿为底稿，参考 Argon 压缩重复问路、传话与往返，保住借扇条件、骗局凭据、关键反应及还扇承诺。若优先控制阅读长度，Argon 已是更合适的候选。Claude、DeepSeek 的现有稿件可以评价，但尚未完成的审核不能算通过，也不能据此给出它们最终成稿的排名。

以上结论只针对这一个故事及当前保存版本，不推广为模型的普遍能力排名。

这里只比较文本分镜、画面指令和生产审核过程。Flash 的 16 张插图，以及采用 Codex 保存分镜另建故事后的 70 张插图，均由 Gemini `gemini-nano-banana-2.1` 生成；Argon、DeepSeek、Claude 没有在本次比较中生成图片。不能把那些图片的画质归给 Codex，也没有五套成图质量的对照结论。

## 故事与共同输入

故事出自《西游记》第五十九至六十一回：唐僧师徒遇火焰山阻路，悟空三次求取芭蕉扇，经历假扇、冒名骗扇与反骗失扇，最终在众神协助下降伏牛魔王。故事还包括灭火之后的讨扇、除根与还扇，不能在牛王被降伏时提前结束。

| 条件 | 五版共同设置 |
| --- | --- |
| 选题 | 路阻火焰山 |
| 原典 | 《西游记》，第五十九至六十一回 |
| 选定原文单元 | 第 59 回 `004–035`；第 60 回 `001–036`；第 61 回 `001–052`，均为项目原文单元编号 |
| 主题 | 原典故事 |
| 叙事详略 | 适中（`balanced`） |
| 幅数策略 | 自动（`auto`），未给各版统一指定数量 |
| 画风 | 古典油画（`classical-oil`） |
| 语音 | 关闭 |
| 自定义验收要求 | 无 |

五版选定原文和章节上下文分别相同，后文给出 SHA-256。完整共同制作要求如下：

> 按原文自身的事件、人物与因果展开，不额外套入主题或要求反转。完整讲清原文主事件的起因、关键行动与结果，首幅自然介绍人物与处境。按事件顺序展开，保留关键对白、反应和停顿；每幅一个静态可见瞬间，相邻幅各有任务。配文自然明白，画面动作与关系可读。结语在独立结束页提炼一层有据的认识，不复述情节、不虚构动机或扩大因果。

这些是同一生产工作流保存的独立制作结果，未把某版分镜交给另一版照写。Flash 从选题流程进入；后续独立比较沿用已确定的故事和来源，省去了重新发现选题。所以上述条件相同，不意味着五个完整调用过程、提供方请求格式和运行历史完全相同。

Claude 的 selection 与先前 Codex 结果结构相同；其 14 条已保存调用的 verifiedOriginal 原文和章节上下文也逐条匹配相同哈希。DeepSeek 保存结果核实了原文、完整章节上下文及用户制作要求一致。生成的摘要、方案、提供方请求格式和运行历史仍可不同。

文本任务请求档位沿用原设置：画幅建议 medium、提纲 high、分镜 high、审核 high、修订 high。档位名相同不代表不同提供方使用相同计算量；Claude 的 effort 是 CLI 请求值，实际模型来自响应回执。DeepSeek 将配置的 medium/xhigh 映射为 high。

Flash 并非没有主线，而是很多有效的中间动作只剩一句交代。Argon 的 41 幅已经说明：**16 幅不能代表 Gemini 系列在这个故事上的全部表现，也不能仅凭模型名带 Flash 就认定原因。** 换成 Argon 后，初次求扇、化蟹潜潭、真扇得失等过程都明显展开。

Codex 也不应因为幅数最多就免于编辑。它保留了更多往返、传话和接应；这些停顿是否都值得独立占幅，仍可以按目标读者再作取舍。本次保留的是已通过审片的 70 幅成稿，没有为比较文档重新合并或修改分镜。

## Claude 待审稿具体表现

### 借扇冲突保留了条件变化

Claude 当前第 8–10 幅保留了罗刹因见不到红孩儿而怨恨、悟空许诺借扇后请子相见并还扇、主动伸头受剑、对方仍拒绝后转为动武。第 9 幅明确写“伸过头来让我砍几剑，受得住就借”，画面也取受剑的一刻。

这比 Flash 第 3 幅把旧怨、受剑与扇走合在一起更容易读出求借如何转为交锋；与 Codex 第 7–12 幅同属保留人物条件与回应的处理。Argon 第 7–10 幅也已展开冲突，不能把这些能力说成 Claude/Codex 独有。

### 骗真扇的心理与道具链条较完整

Claude 第 34–39 幅分出冒名获得接纳、假意痛惜、得知先前是假扇、结发妻提醒、疑小扇不能灭火、借醉授诀、现形羞辱、试出真扇却不会缩小。尤其第 37、39 幅让“怀疑—得到口诀—验证—留下疏漏”连起来，不是酒后直接交出万能宝物。

这部分接近 Codex 第 34–40 幅的展开，明显比 Flash 第 9 幅紧缩得少。Argon 第 25–27 幅也交代了吐扇授诀与现形，只是分配更紧凑。

### 67 幅仍不代表每个关键动作都展开

Claude 当前第 60 幅用一段配文交代斩头再生、火轮、照妖镜与归顺；prompt 同时出现白牛“仰头哮吼”和“低下头作求饶状”，一个静态瞬间的姿态仍需取舍。Codex 第 59–60 幅把斩头无效与火轮照镜奏效分开，在这一处更清楚。Claude 当前第 63 幅还把息火、生风、降雨放在同一配文，画面取第三扇后的细雨；Codex 第 63–65 幅分别承载三扇。

这是当前未审完稿的具体问题，不应把它冒充 Claude 最终未能修复的错误；后续全篇审核尚未执行。

### 结尾保留履约

Claude 第 64–67 幅保留罗刹讨扇、八戒拒绝、悟空问除根法、四十九扇与次早还扇，没有在牛王降伏时提前结束。比 Flash/Argon 的末尾更细，仍比 Codex 第 63–70 幅紧凑。


## DeepSeek 待审稿与修订退化

DeepSeek 从 49 幅初稿保存为 50 幅，经历 8 次全篇审核／复核和 10 批修订后，按用户要求停止，生产控制保持 paused。审核发现过图文时点、服装、人物位置和往返路程等问题，但修订也会引入新问题；目前不应让它独自担任最终审片。

一个明确例子是当前第 44 幅：配文仍写“牛头随落随生”，prompt 却要求“颈上生出数个牛头”“多首白牛”。原文是逐次斩落、逐次再生，Codex 第 59 幅明确保留一颗再生头，并说明不画成同时多头。这是事实与静态画面控制的差别，不是多一幅或少一幅的问题。

第 5 次全篇复核还把“两股毫毛”解释为“两股或两缕毫毛”。这里的股应结合原典作大腿义理解，而非两缕毛；大腿义可查[教育部字典](https://dict.revised.moe.edu.tw/dictView.jsp?ID=4179&word=%3D%E8%82%A1)。审核意见本身也会误读原文，自审通过与否都不能代替逐项核对。

DeepSeek 本次使用官方 `deepseek-flash` API 别名、独立环境密钥和固定 DeepSeek 端点。32,768 tokens 的复核曾全部耗在 reasoning，返回 `max_output_tokens`；提高审核输出预算后，一份报告记录 35,128 reasoning 加 2,529 正文 tokens。另有完整报告被本地校验拒绝，之后用精确原文引用 ID 还原规范短引，再进入同一共享校验。没有放宽验收、豁免审核或切换提供方。先前 62 项聚焦回归、类型与 lint 检查通过；这些验证不等于该故事完成。

## 已通过三版的制作与图像交付

Argon 从 38 幅初稿经数量审核与一批修订增至 41 幅；Codex 从 68 幅初稿最终增至 70 幅，保存了三次数量审核／复核和三次全篇审核／复核、四批修订。Codex 的修订涉及主动受剑、侦察后改用骗术、真扇验证、八戒误责后的反应，以及牛王变化状态等具体问题，并非单纯要求“再多写几幅”。

制作过程中出现过提供方输出预算、schema 兼容或输出校验故障，并经过明确重试。提供方请求适配得到修复，本地验证与正式审核门保留，三版最终均没有人工豁免。因这些运行历史并不相同，这份记录是实际制作案例，不是严格的同时同配置模型基准测试。

之后按用户选择，把 **Codex 已保存的分镜、原文和通过审片的检查点复制为独立新故事**，没有重跑文本生成或重新审片；由桌面当前的 Gemini `gemini-nano-banana-2.1` 补齐 70 张图片，并通过应用的一页 PNG 导出得到 70 幅总览（1824 × 15956 像素）。原 Flash 故事的 16 张图片保留，Argon 未启动绘图。

就这个故事而言，选择 70 幅意味着需要交付的画面数是 16 幅的 4.375 倍、41 幅的约 1.71 倍。更细的叙事会增加绘图工作和阅读长度；这些比例不等于费用或耗时比例。本次没有统一口径的三方总耗时、token 和账单对照，因此不作速度或价格排名。

| 26 | 女子大骂：“那贱婢不知羞，牛王全靠我供养，还来请他！”悟空认出她是玉面公主，掣棒喝道：“你拿家私买住牛王，是陪钱嫁汉，倒敢骂谁？”女子吓得逃回洞里关门。 |
| 27 | 玉面公主扑进牛王怀里大哭：“原来你是个怕老婆的庸夫！”牛王哄了她许久，说山妻家门严谨，哪来雷公嘴的男子，怕是妖怪冒名，要出去看看。 |
| 28 | 牛王披挂出门。悟空唱喏：“长兄还认得小弟么？”牛王斥他害子、欺妾，悟空辩说红孩儿已成正果，又赔罪惊了二嫂。牛王道：“看在旧情，饶你去罢。” |
| 29 | 悟空又求他一同去向大嫂借扇。牛王咬牙大骂：“原来是为借扇！先欺我妻，又赶我妾！”说三个回合敌得过，才让山妻借扇，随即抡棍劈头就打。 |
| 30 | 两人从山前打到半空，斗了百十回合，不分胜负。山峰上忽然有人叫道：“牛爷爷，我家大王请您早去入席！”牛王用棍架住金箍棒：“猢狲，你且住手！” |
| 31 | 牛王回洞骗玉面公主，说已把猴子打跑，随后卸甲换上鸦青绒袄，骑着辟水金睛兽往西北去了。悟空变成一阵清风，紧跟在后。 |
| 32 | 悟空跟到“乱石山碧波潭”，变成三十六斤重的螃蟹潜下水去。宫中正在宴饮，老龙喝令拿下野蟹；螃蟹自称“横行介士”，不懂礼数，求饶命。众精求情，放他到外面伺候。 |
| 33 | 悟空逃到牌楼下，那里拴着那头辟水金睛兽。他暗想：牛王散了席也不肯借扇，不如偷他的坐骑，变成他的模样去哄罗刹女。于是现出原身，解下缰绳。 |
| 34 | 悟空变作牛王模样，骑兽驾云来到芭蕉洞。女童开门一看，进去通报：“奶奶，爷爷回家了！”罗刹女连忙整理发鬟出门迎接，拉着他的手进洞，一家上下都恭恭敬敬。 |
| 35 | 假牛王说要捉悟空报仇。罗刹女含泪说那猢狲钻进她肚里，险些害了她性命，只好交出扇子。“牛王”捶胸叫可惜，她却笑道：“给他的是假扇，真扇我收着呢。” |
| 36 | 她摆酒敬道：“新婚千万莫忘结发妻。”悟空不敢破荤，只吃果子。酒过数巡，罗刹女半醉偎肩，悟空趁机问真扇收在哪里，她笑嘻嘻从口中吐出杏叶大的小扇：“这不就是宝贝？” |
| 37 | 悟空疑心这么小的东西灭不了火。罗刹女把脸贴到他脸上：“亲亲，别出神了。”又借酒说出秘诀：左手大拇指捻住扇柄上第七缕红丝，念一声咒，就长到一丈二尺。 |
| 38 | 悟空把扇子含进嘴里，抹脸现出本相，高叫：“罗刹女，你看我是你亲老公吗？缠着我做了这许多丑事，羞也不羞！”罗刹女推倒桌席，跌在地上，连叫：“气杀我也！” |
| 39 | 悟空跳上高山试咒，扇子果然长到一丈二尺，三十六缕红丝闪着祥光，和那把假的果然不同。可他没问收小的口诀，只好扛在肩上往回走。 |
| 40 | 碧波潭散了席，牛王出门不见金睛兽。龙子龙孙说刚才有个蟹精进来过。牛王顿时醒悟：“准是孙悟空变的，偷了我的坐骑，去山妻那里骗扇子了！” |
| 41 | 牛王赶回芭蕉洞，罗刹女揪住他骂：“怎么这样不小心，让那猢狲变成你骗我！”牛王咬牙说要剥了猴皮给她出气，脱下宴袄，拿起她的两口青锋剑追了出去。 |
| 42 | 牛王追上悟空，见他扛着扇子满面得意，便藏起宝剑，变成八戒的模样迎面走来：“师兄，我来了！师父见你许久不回，叫我来接你。” |
| 43 | 悟空得意地说了骗扇经过，顺手把扇子递给“八戒”。牛王接过来捻诀，扇子缩成杏叶大小，随即现出本相骂道：“泼猢狲，认得我么？” |
| 44 | 悟空跺脚自悔：“终年打雁，今天反被小雁啄了眼！”挥棒就打。牛王举扇猛扇，悟空先前不觉咽下了定风丹，纹丝不动。牛王慌了，把扇子丢进口中，挥剑就砍。 |
| 45 | 路边，三藏又热又渴，问土地牛王法力如何。土地说正是大圣的对手。三藏担心悟空久去不回，派八戒去接应。八戒不认得路，土地便领他前去，留沙僧陪伴师父。 |
| 46 | 八戒赶到，悟空骂他误事，又说牛王冒充他的模样骗走了扇子。八戒大怒：“你这遭瘟的，敢变作你祖宗的模样骗我师兄！”抡钯没头没脸乱筑。 |
| 47 | 牛王斗了一天已经力乏，敌不住八戒，转身败走。土地领阴兵挡住去路，劝他交出扇子。牛王骂道：“那泼猴夺我子、欺我妾、骗我妻，我怎肯借他宝贝！” |
| 48 | 三人边走边斗打了一夜，天亮时到了摩云洞口。玉面公主派出百十名小妖助阵，八戒措手不及，拖着钯败走，悟空驾筋斗云跳出重围，阴兵四散，牛王收兵关门。 |
| 49 | 八戒泄了气：“扇子难得，不如回去绕路走吧。”土地劝道：“绕路就是走旁门。古语说‘行不由径’，你师父还在正路上眼巴巴等着呢。”悟空发狠：“土地说得对！”八戒也来了劲。 |
| 50 | 两人带阴兵打碎摩云洞前门。牛王骂着冲出，悟空喝道：“我昨天还与你论兄弟，今天就是仇人了！”三人又斗百十合，八戒仗着师兄乱筑，牛王遮架不住。 |
| 51 | 牛王败退想回洞，被土地和阴兵拦住，慌忙卸甲丢棍，变成天鹅飞走。八戒、土地东张西望，悟空一指：“那天鹅正是老牛变的！你俩打进洞去，剿除群妖。” |
| 52 | 悟空变海东青，从云眼倒扑下来抱住天鹅啄眼。牛王变黄鹰反啄，悟空变乌凤追赶；牛王变白鹤南飞，悟空变丹凤高鸣，白鹤只得收翅落下山崖。 |
| 53 | 白鹤变香獐在崖前吃草，悟空就变饿虎扑来；牛王变大豹，悟空变狻猊；牛王变人熊来擒，悟空打个滚变成大象，伸鼻去卷人熊。 |
| 54 | 牛王嘻嘻一笑，现出千余丈长的大白牛原身：“泼猢狲，你如今能把我怎样？”悟空也现出原身喝声“长”，长到身高万丈，抡棒当头就打。牛王硬着头，用角来顶。 |
| 55 | 这场恶斗惊动了过往神众、金头揭谛、六甲六丁和十八位护教伽蓝，都来围攻牛王。牛王急了，一滚恢复本相，逃进芭蕉洞闭门不出，众神把翠云山围得水泄不通。 |
| 56 | 八戒领土地和阴兵赶来，说已一钯打死玉面公主，原来是只玉面狸精，群妖剿尽，洞府也放火烧了。听说老牛躲进了芭蕉洞，他发狠举钯一筑，把石崖连门筑倒半边。 |
| 57 | 洞里，牛王喘着气，把扇子从口中吐出交给罗刹女。她满眼含泪：“大王，把扇子送给那猢狲，叫他退兵吧。”牛王道：“夫人啊，东西虽小，仇恨却深。”他重新披挂，提剑出门。 |
| 58 | 牛王在翠云山上拼死斗了五十多合，抵挡不住，往北逃，被奉佛旨的金刚拦住；转向南、东、西，又各有一位金刚挡路。四面八方都是佛兵天将。 |
| 59 | 牛王往天上逃，托塔天王和哪吒奉玉帝旨意拦在空中。牛王又变成大白牛，用铁角去顶天王，天王挥刀来砍。哪吒对悟空说：如来发檄奏报玉帝，特派他们来助战。 |
| 60 | 哪吒化出三头六臂，跳上牛背斩下牛头，腔里又长出新头，连斩十几次都是如此。他把火轮挂上牛角放真火，天王用照妖镜照住本相。牛王求饶，愿归顺佛门，说扇子在山妻那里。 |
| 61 | 哪吒用缚妖索穿牛鼻牵到洞口，牛王叫：“夫人，将扇子出来，救我性命！”罗刹女卸去钗环，一身素衣捧扇跪下：“饶我夫妻之命，愿把扇子献给孙叔叔成功。”悟空上前接扇。 |
| 62 | 三藏见满天祥云，害怕地问是哪里的神兵，沙僧一一认出。三藏换上毗卢帽、披上袈裟拜迎众圣。金刚说：“你的功行快要圆满，要竭力修持，不可片刻懈怠。” |
| 63 | 悟空走近山边，用尽力气扇了一扇，火焰平息；第二扇，清风微动；第三扇，满天阴云，细雨纷纷落下。三藏顿觉燥热全消，心里清爽。 |
| 64 | 金刚和众神各自散去，天王、哪吒牵牛回佛地复命，只有土地押着罗刹女在旁。罗刹女跪求还扇，八戒喝道：“饶了你的命就够了，还想要扇子？” |
| 65 | 罗刹女再拜：“大圣原说灭了火就还我，我后悔已晚，再不敢妄作。”土地也请大圣还扇。悟空问：“扇灭了只管一年，怎样才能除根？”罗刹女说：“连扇四十九扇，永不再发。” |
| 66 | 悟空用尽力气，朝山头连扇四十九扇，山上大雨倾盆。真是宝贝：有火处下雨，无火处天晴。师徒站在无火处，身上一点没湿。 |
| 67 | 过了一夜，次早悟空把扇子还给罗刹女：“不还你，怕人说我言而无信。回山去，别再生事。”她把扇捏成杏叶含在口中，和土地拜谢相送。师徒身体清凉，脚下湿润，继续西行。 |
