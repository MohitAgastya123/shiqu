# 书库维护与发布检查验收

所有库、备份、输出及 home 均在隔离临时目录。调用正式维护 CLI/开库/服务；不访问用户数据、不产生真实模型调用。

1. 完整库含故事、旧新版本、暂停/失败任务、阅读进度和媒体：停服备份→校验→恢复到新目录→只读启动，比较数据与媒体哈希，旧库不变。
2. 已有目标、源目标嵌套、缺文件、增加文件、篡改、清单路径越界及符号链接：拒绝，已有目标/库/外部文件不变，无半恢复库。
3. 服务持有书库锁：备份拒绝；停服释放后可备份。维护操作在无提供方配置与禁止网络下成功。
4. 旧结构库升级：迁移前生成旧结构备份且可恢复，重新打开不重复备份。快照失败时旧结构和媒体不变；失败迁移的已验证备份仍保留。
5. 开发/CLI/桌面启动和已知任务错误产生安全事件；任意错误正文、密钥、原文、路径不进入日志/诊断；大量事件轮换后容量有界，写日志失败不破坏生产。
6. 正常/损坏/缺失数据库导出诊断：受限版本与计数可读，绝不复制Document、selection、错误原文或凭据；输出不覆盖已有文件。
7. 本地发布门执行现有E2E，E2E失败会阻止后续发布；tag检查依旧针对发布提交，保留用户工作区。
8. 执行现有 `pnpm test:e2e`，确认新增服务锁、迁移快照和诊断不改变新建/编辑/暂停/重试/替换的正式流程。C007 在一次性源码根目录运行真实 `pnpm dev local`，checkout 内人工 dev-local 与其占用服务均不受影响。
