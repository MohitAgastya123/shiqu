# 手动启动提取

1. 选择书籍、原文和主题，点击“进入故事提取”。窗口显示具体原文/主题及“自动标题、输入标题”，没有正在查找提示。API、轮询与生产观看不会产生提取调用。
2. 切换标题方式、输入/修改文字不启动。自动方式点击“开始提取”，输入方式填写标题点击“按标题提取”，才产生search命令并显示结果。
3. 等待状态关闭/重开及刷新仍不启动。已提交搜索继续按既有流程保存、续查，重放同一命令不会重复调用。
4. 已有故事打开重选，父故事不变且草稿无提取调用；点击按钮后才能查找，取消后原版本保持不动。
5. 三个水浒章节、单篇故事原文与主题组合均保留；390px下等待条件与按钮清晰、无水平溢出。
