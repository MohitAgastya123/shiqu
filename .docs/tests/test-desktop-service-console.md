# Desktop service console E2E

Use pnpm desktop:preview in the in-app browser and isolated settings/home/library fixtures; no real credentials, inference or packaging.

1. Fresh console: one view, no tablist, queue, story metrics, deletion or provider/key form. Native-IPC fixture starts without configured provider; start reports starting/upgrading/running, browser opens only after running. Failure retains safe error and backup; unknown polling is never stopped. Runtime, native paths/port, pickers and quit remain visible/reachable. Native controls lock while running or unknown; stale save instructs reload.
2. Browser first run: local service opens shelf/read status without provider. Setup prompt opens 我的 → 生成服务与模型; `/#provider-settings` opens that form only at local-authorized origin. Generation fails before production creation. LAN/tunnel retains reading/generation and host-only setup prompt with no settings entry.
3. Settings: load/save both provider profiles, separate image provider, models/reasoning and keep/replace/remove synthetic keys. Saved keys never appear in response/DOM/log. Saving shows restart-needed and leaves runtime unchanged. Check sends no drafts and performs only metadata/login status; reset requires confirmation and preserves native fields/library. Concurrent native/browser saves preserve other fields or reject stale revision.
4. Restart: runtime summary matches browser startup snapshot; saved drift matches browser restart-needed including overrides/key changes. Active production requires explicit confirmation that work stops and is resumable; cancel leaves service alone. Stop/start/restart errors recover without duplicate starts. Open-reader allows root and one fixed generation-settings fragment only.
5. Security: real HTTP automated tests deny LAN peer/address, foreign origins, spoofed forwarding headers, normalized route variants and tunnel settings; no native control or path mutation endpoint. Exact settings path wins over platform environment directories; missing/corrupt database returns safe error without creating another store. Legacy library startup upgrades before ownership and records verified backup; recovery failure reports available backup safely.
6. Disclose IPC simulation versus native OS runtime evidence. Run applicable Node/Rust suites, typecheck/lint/format; do not prepare/package.
