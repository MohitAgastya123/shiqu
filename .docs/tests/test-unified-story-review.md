# 正式审核流程ET

1. 自动稿在真实production queue中收到reduce及两个同幅完整需求：不调用full或image，结构修订收到未截断需求；减幅后保留对应已有图及阅读位置；再次count=keep后下一检查点才调用full并处理候选结语，最后才派发缺图。
2. count=keep成功保存后暂停并重启：恢复从full开始，count调用仅一次、usage保留；full失败后重试亦不重复count。数量审核在途暂停时保存完成结果，不继续full或绘图。
3. full要求结构变化：结构保存后回count；full只要求局部文字修订：局部修订后直接full。数量门与全篇共用20轮限制，无变化或非法引用不进入绘图。
4. 固定幅数旧稿仍原全篇审核；已通过/未启用审核的旧稿打开不补数量审核。真实稿最终核验暂停，当前复用图与已有字节匹配，无队列running任务。
5. 浏览器打开当前精简稿及桌面预览：显示与实际检查点相符的数量或全篇审核阶段，暂停/阻断信息一致；原有图片可读。只验证显示，不点击恢复生成。
