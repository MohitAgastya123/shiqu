# 自动幅数与原文审核的受控验收

1. 新任务选定故事，原文已保存：编辑叙事详略为详细后确认制作；界面无幅数输入，保存 `length:auto`。提纲自主决定与前期建议不同的数量，完整生成并审核后才绘图。
2. 自动故事已有完整分镜：初审指出一段关键回应被压缩；结构编辑插入一幅并删除重复过渡。新数量和顺序原子保存，随后全篇复核；复核未结束时图片调用为0。
3. 结构编辑将原文中一段重复讲述合并：数量减少，读取/进度不会越界；保留配文与画面的因果，修订记录可看到前后数量及编辑范围。
4. 注入重叠、逆序、越界、空操作、0/81幅及无实际变化的编辑：不修改已存稿或错配图片，清楚失败，绝不绘图；合法检查点重启后不重复付费步骤。
5. 带已绘图片的修订：在中间插入一幅，后续不变画面移动仍正确复用；改变某幅 prompt 仅使其失效；纯配文不失效；首幅改变使依赖图片失效；重复提示词不跨位猜配或一图多用。父版与独立媒体保持。
6. 旧数值故事/无 coverage 回执可读；旧数值 API 可完成原流程。用户从新 UI 按详略重编后进入 auto。源故事/设置被其他操作修改时原有 CAS/幂等保护有效。
7. 审核回执保存可定位的原文短引、任务、幅号和理由；引用不存在、幅号越界或需改项没有相应问题时不能通过。摘要/旧提纲有误不能覆盖原文事实。仅说到事件但画面焦点无关、连续同姿/状态倒退、关键回应缺失均可表示为具体问题。

8. 旧 `[A,X₁,X₂,B]` 经明确结构操作变为 `[A,Z,X₁,X₂,B]`，X₁/X₂提示词相同而图片不同：严格检查新第3幅来自旧第2幅，新第4幅来自旧第3幅，且一张图不重复用。无来源映射的全篇重编对重复X保守不复用。旧数值故事仅改配文/画风不切auto、不冲突；明确按详略重编时才切auto。

服务执行使用受控提供方，不追加真实模型调用或图片。浏览器复用当前内置浏览器，核对详略控制、自动数量文案与暂停/确认界面，避免触发真实书库任务。
