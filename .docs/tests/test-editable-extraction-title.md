# 提取窗口标题编辑

使用隔离生产服务、可控推理和独立测试浏览器。

1. 新建条件窗口中没有标题输入，书籍/主题/范围可选，主按钮上方留白至少20px。
2. 进入提取窗口后显示可选标题输入。填写“乌龟报恩”点击按标题提取，生产请求携带search/title，结果只显示本轮故事，主题和范围保留。修改输入本身不发请求。
3. 改为另一个标题并再次提取；旧候选被替换。清空后点击自动提取，保存auto模式。重开窗口显示最后提交标题。
4. 旧自动提取尚未完成时提交标题；旧结果晚到不混入新结果。
5. 已有故事重选草稿显示同一标题控件，修改并提取不改变父故事；取消保留父版本。
6. 390px宽度下标题、提取按钮与候选无水平溢出，操作按钮与上方控件有明确间距。
