# 选题条件界面验证

使用隔离测试服务和独立测试浏览器；不提交真实书架任务或运行图片生成。

1. 新建入口分别展示可选故事标题、主题、原文范围。遍历三条件的8种组合；标题留空自动发现，不限定主题使用原典故事，范围留空使用整本书。每个提交保留选定条件。
2. 标题填写“宋公明三败高俅”，选78—80回并选“欲望与代价”；选题页显示目标和主题用途，选择后主题保留。只选78回时结果为空并提示补选。
3. 选择一个已有故事段落并填对应标题；提交保留准确段落范围，提取输入不含该章其他故事；清空标题恢复已有故事直接选择。
4. 换书清除旧出处和标题。非本地书籍保持自动发现能力；按标题输入提示仅本地书籍可用。
5. 窄屏检查标题、主题、范围及主按钮，无水平溢出；空白标题可自动发现，空白自定义主题不能提交。
