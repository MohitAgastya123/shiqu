# Comic bubbles E2E specification

Run against an isolated library, fixture image and fake provider using production generation/revision/export code. Never use the user's library or live model account.

- [x] Give the production workflow an English fixture story with explicit spoken words and an explicit thought, and receive the finished comic without opening an editor. Verify attributed speech/thought balloons, exact source evidence, separated narration, automatic non-overlapping in-bounds fitted positions, planned speaker tail targets, saved revision and visible reader layer. Reject unsupported evidence and invalid geometry.
- [x] Exercise four long balloons, maximum text, an unbroken word, multiple thought clouds and obstructed/crossing tail targets. Verify readable bounded fitting and connector/body separation. Exhausted capacity must produce a density error handled by the existing bounded generation/repair retry, preserving all text and requiring no manual placement.
- [x] Open a legacy story with no balloon fields. Read and edit it without automatic model calls or changed image/export behavior.
- [x] At desktop and mobile viewport sizes, read both balloon kinds. Verify complete artwork, pointed speech tail, thought circles, legible text, ordered accessible transcript and no narration overlap or clipping.
- [x] Open a revision draft. Add speech and thought, edit text/speaker/kind, reorder and remove. Move, resize and aim a balloon with pointer/touch, keyboard and numeric inputs. Show clear errors for invalid positions or excessive text.
- [x] Close/reopen or discard an unsaved editor draft according to the existing draft contract; ensure no implicit server save. Save a layout-only draft and reload. Verify new revision, retained original revision, identical artwork and no paid review/image call.
- [x] Save changed balloon content. Verify production review sees the changes, artwork reuse remains valid, and unsupported thoughts cannot bypass review. Submit a stale revision and show the existing conflict behavior.
- [x] Export PNG, PDF, internal/public ZIP, JSON/Markdown and offline HTML. Verify visible speech/thought shapes, complete text and attribution, no duplicate painting, readable WebPs and valid hashes/XMP. Convert an existing ZIP and verify image bytes unchanged.
- [x] Run focused tests plus repository-selected regression checks, inspect desktop/mobile and export screenshots, and record commands, results, artifacts and any tool limitation in the completion doc.
