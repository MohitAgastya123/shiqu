# 开发数据库 E2E

执行命令：计划新增`pnpm test:e2e`。场景及断言以[测试用例](../../.tests/story-lifecycle/CASES.md)为准。

1. local启动：即使.env指定其他目录也只使用`.data/dev-local`；无local参数沿用原规则。非法参数报错，私有SQLite不可被Vite下载。
2. 新建完整UI：选择原文/主题、打开提取、刷新等待、输入标题或自动提取、选定、草稿编辑、重新准备、最终确认、完成阅读。确认前无plan/image。
3. 编辑完整UI：改名不生成；草稿关闭/丢弃；制作要求、验收、画风、叙事、分镜及结语分别走真实修订；书架仅最新版，原版历史不改，适用时复用图片。
4. 暂停/恢复及失败：受控模型挂起/报错以稳定触发真实持久状态；通过UI按钮恢复或重试，刷新不买新尝试；已保存检查点复用。另触发审核无变化阻断，验证手动修订重审和明确跳过绘图，保留人工放行标记。
5. 重选：打开不提取，取消不变；明确提取并选定才替换，新版需确认制作，原版保留且单卡片。
6. 协议补充：停止、幂等、迟到回执/过期命令、服务重启、同家族并发、图片失效/恢复。复用既有真实REST/生产fixture测试，明确标注不是浏览器点击证据。
7. 保存截图、trace、状态转换、测试库位置、命令结果和Run ID；异常分类为产品/测试/环境，不以重试掩盖问题。
