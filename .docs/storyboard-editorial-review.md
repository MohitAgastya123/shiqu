# 从原文发现分镜问题：审核方法与执行约束

这套方法来自一次真实的《红楼梦》九篇文字分镜重编。判断对象是原文与文字分镜；旧图另行检查能否复用。它不证明未生成的图片合格，也不保证模型每次都能发现所有问题。

## 问题为什么会漏过

原有九篇都曾通过系统审片。主要漏洞不是“没有提醒忠于原文”，而是把三个不同问题混在了一起：事情有没有提到、人物戏有没有展开、文字能否被一个静态画面承担。故事可以因果完整，却把听懂之后的迟疑、反驳、照料或无言压进一句说明。每幅配文都有新内容，画面也可能仍是同一个人、同一个姿势和同一焦点。

原有流程先锁定幅数，再要求局部修订不得增删幅号。审核即使认为需要多一拍，也容易继续压缩旁白，或退回要求用户手定数量。仅增加提示词中的“注意细节”不足以证明这个问题已经解决。

## 1. 先固定事实范围

读取故事已经保存的版本、定位原文与完整章节上下文。主事件的诱因、行动、关键转折及自然终点必须先确定；不能仅凭标题、摘要、读过整部书的记忆或旧提纲决定终点。标题偏窄不等于读者要求节选，章节中独立支线也不因此全部收进来。

区分正文事实、人物判断、内心独白、诗中设想、转述往事和人物编造的故事。后四者可以有叙事价值，但不能画成眼前确实发生的事件。比如耗子故事始终是宝玉在卧房里讲述；葬花诗里的双翼、风刀霜剑也不能变成真实飞行、刀剑或新的逼害者。

## 2. 从原文提取有叙事作用的言行

先不看当前多少幅，按事件顺序问：

- 谁做了什么或说了什么，使处境、所知信息或关系发生变化？
- 谁承受这句话、这个动作？他听懂、误解、躲避、反驳或接纳之后，有什么原文写明的回应？
- 回应是否改变下一步？若删去，后面的行动还成立吗？
- 原文在哪里停了一下、转移目光、收回手或沉默？这个停顿是否具有独立作用？
- 自然结局是否已经发生，还是刚介绍一个目的、计策或打算？

这不是按原文段落平均分幅，也不是每句话都配一张图。同一瞬间可同时呈现的动作与回应可以合并；先后发生、改变关系的几拍应分别安排。区分三层轻重：决定因果/结局的内容必须保留，支撑人物关系和意味的内容按叙事详略展开，重复说明、清单及纯操作过程可以压缩。

简短也不能丢关键因果，详细也不能以重复站姿凑数。环境不是装饰性空镜：门第尺度、冷热、露水、空座、未被接过的物件，可以承载原文中的观察、处境或停顿，但不能自行添加象征性的雨雪与灾祸。

## 3. 做两向对照，区分缺失与合理删节

**原文到分镜：** 每项重要任务有没有真正获得画幅？配文是否只说到了，画面却在表现别的事？缺的究竟是事实、说话力度、听者反应还是过程节奏？

**分镜到原文：** 画面与配文里的行动、动机、因果、时间及物件状态有没有依据？新加细节是否改变了原作？人物自己的指控是否被旁白当作事实？

需要保存的核对记录是“原文短引—叙事任务—对应幅号—判断与理由”。短引用于定位，任务说明为什么值得保留，幅号说明落实在哪里。找不到对应画幅的缺失项不能用一个伪造幅号冒充覆盖。取舍理由也不能只是“更有感染力”“增加细节”。

审核应独立建立对照，再核对已有分镜。作者的覆盖清单、核对摘要、旧提纲或“AI演绎/节取至此”的改编说明，都不能自证完整。压缩本身不是错误；只有造成可说明的理解、性格、关系或节奏损失，才要求修订。

## 4. 连读每对相邻幅

逐对检查主要动作、身体接触、朝向、视线、第一焦点、物件持有者与状态、时间及已经揭示的信息，包括技术批次边界。不能因为台词换了、论点变了或景别变了，就认为画面有了新的任务。

重点查三类伪推进：同一动作重复完成、同一信息重复说出、同一情绪仅换形容词。拿到纸、低头读纸、带纸离开可以有三个任务，但不能连续两幅都停在案旁托纸低头。听者的无言与细微变化可以保留，不过必须说明它承接了哪句话、与上一幅有什么实质区别。

单幅还要核对说话者、对象、条件、否定、反问和力度。保留有表现力的原句，不把潜台词全翻译成心理解释；现代译写则须读清古今异义和省略。必要的一句背景，应帮助当前交锋成立，不能另开长支线。

## 5. 判断用哪种修法

| 问题 | 足够的修法 | 不足的修法 |
|---|---|---|
| 称呼、条件、说话对象含混 | 只改配文，保留有效画面 | 全篇重编或强加心理解说 |
| 画面焦点不承载当前言行 | 改该幅静态瞬间/听者回应 | 只换景别或加一段旁白 |
| 关键先后动作挤在一幅 | 有依据地拆幅，保留原顺序 | 把动作都写进配文 |
| 相邻幅无独立任务 | 合并或删除，保留有效信息 | 为维持幅数增加空镜 |
| 重要阶段/结果整段缺失 | 调整局部连续结构，再全篇复核 | 在末幅补一句结果或结语 |

自动幅数模式应允许有界增删，数量是完成上述任务后的结果。首次估计不是承诺，审核不能为了迎合它保留重复或省去关键回应。系统仍保留1–80幅的执行边界；无法在边界内完整表达时应清楚停止，不能截断故事来伪装完成。

## 6. 实际发现的几类问题

以下是公开原作情节对应的问题类型，不依赖私人制作要求或图片。

| 场景 | 初看容易通过的理由 | 原文对照后发现的损失/错误 |
|---|---|---|
| 黛玉初进贾府，王夫人告诫宝玉 | 配文已经包含告诫、回答与传饭 | 一个画面以传饭人为焦点，告诫与黛玉谨慎回应没有真正展开 |
| 凤姐出场与称呼 | 招呼、身份与见礼都有 | “先闻其声”与现身重复同一句招呼；黛玉一时不知如何称呼的一拍又被略掉 |
| 赠字颦颦 | 有黛石画眉、探春质疑及宝玉回嘴 | 缺了宝玉声称依据某书的应答，或赠字仍沿用前幅均衡对坐构图，关键对应没有焦点 |
| 黛玉葬花 | 保留惜花、洁净与生死 | “风刀霜剑严相逼”、花可再发而人未必能待等层次被压掉，容易只剩一场爱情误会后的伤心 |
| 宝玉闻葬花诗 | 已经写他恸倒 | 新增幅仍重演衣襟松开、花瓣散地；应承接已完成状态，把悲意扩展到园中人事的追问 |
| 宝黛怄气 | 摔玉、吐药、剪穗及和好都在 | 他希望她体谅，她却把急于辩白理解成仍在意金玉婚配；双方不同的亲近期待没有展开 |
| 香玉耗子故事 | 双关结论还在 | 请差、自夸、偷法、变错与揭底只剩两幅；补幅后又需检查连续讲述的站姿/卧姿重复 |
| 宝钗加入话香 | 三人都在画面里 | 配文是宝钗反击忘典，画面却让黛玉开口，提前消耗下一幅叫好的回应 |
| 药方风波，次日重提 | 原文事实大体都在 | “次日赏礼”误把得知昨日赏礼写成次日才赐礼；裁剪从炕上被写到案桌上，承载面倒退 |
| 宝玉参禅 | 使眼色、两边受责与写偈都有 | 湘云以为他偏护黛玉，黛玉却以为他偏护湘云；这层相反解释若缺失，两边责怪的逻辑就变薄 |
| 袭人听错衷情 | 表白、惊醒、离开和掩饰都有 | 几个先后反应可被末幅一口气概括；只有借口出现，未给惊惧与掩饰之间的变化空间 |

## 7. 保存、复核与旧图

每轮保存实际问题、原文依据、修法、修改过的画幅及前后数量。修订后必须重新连读全篇，既核对旧问题是否解决，也查修改引入的重复、时间错误和状态倒退。没有实际变化、结构输出非法或修订达到上限时停止绘图，不把失败当作通过。

图片复用依据实际绘图输入，不依据“原幅号不变”或“文本看着差不多”。画风、全局要求、人物和首幅参考稳定，且某幅 prompt 精确一致时，移动到新位置仍可以复用；每张旧图最多用一次，重复提示词不跨位置猜配。首幅改变须重算依赖；纯配文修改不应迫使重画。原图复制到新版自身空间，不能依赖父版文件永远存在。

## 离线验证的审核顺序

用户确定的幅数审核顺序是：先从原文找出有独立作用的言行、回应和停顿；找到旧稿对应幅，分别检查配文与画面；判断是否只交代结果却省掉关系变化的过程；最后写具体补戏要求，重编后才计数。无需另做一次原文提取调用，也不把人工逐篇清单交给模型。

数量门只输出实际补戏需求和数量结论。每条保留原文连续短引、原幅锚点、独立作用、旧配文与画面证据、压缩损失和修法。非keep必须有需求，keep必须需求为空且数量不变；建议数不是配额。模型修改后回到原文全篇复核，不能只检查“是否照指令加了几幅”。

测试循环为：旧制作稿→幅数审核→结构修订→幅数复核，直到有据keep，再执行原有事实、语言、构图、连续性、标题及结语审核。全面审核再次要求结构变化就回数量门，纯局部修改后继续全面复核。实际稿未达标就保留问题，非法输出、无变化或20轮上限均停止而非通过。

本轮仅以共用生成器配合离线适配器测试v1→v2。正式书架、制作队列和UI没有接入这道新阶段，也未生成图片或音频。检查点绑定原稿/原文/设置/模型/源码版本，成功请求按完整内容哈希复用；费用和阶段核对以原始回执和离线gate记录为准（旧engine单轮usage不包括合并执行时的数量keep调用）。九篇的人工参考仅在事后独立验收侧使用。

## 本次证据的边界

九篇从218幅重编为280幅，新增62幅；140张旧图按文件哈希核对后复用，3张因画面任务改变未复用。共27次全篇文字审核、18次文字修订调用；这些数字描述这一批的实际工作量，不是推荐预算、质量分数或稳定效果承诺。所有新版本暂停，未为新增画幅调用生图。

这次人工先列重点，再由 Codex 连读复核，确实发现了旧审核遗漏的具体问题，也修正了重编稿自己引入的问题。它不能证明仅更换提示词就能普遍提高质量。系统改动应靠可检查的审核记录、结构修订闭环、受控回归与后续真实样本共同验证。
