# 每本书一幅星标参考图

用户可在故事任一已保存图片的画幅上打星，用它作为同书后续生图的参考；每本书最多一幅，选新图替换旧星，再点可取消。用户明确没有星标时仍保留本篇后续参考首图的现有行为。

- [x] 每页有可访问的星标按钮，显示当前画幅选中状态；无图和独立结语页不可设星。保存中禁止重复提交，失败保持服务端真实状态并可重试，翻页/换故事时不串状态。
- [x] 每个用户、每本书至多一个星标，跨故事/版本共享，换书互不影响；设星、替换、取消及重启后状态正确。生成故事及已发布故事的本地图片可选，用户不可指定任意文件或远程URL。
- [x] 星标参考用于同书之后实际派发的生图，包括新故事第一幅；无星标时原有本篇首图参考行为保持。Codex、Gemini、OpenAI均实际收到图片，不只是文字说明；现有画风和新场景仍决定构图/行动，不复制参考图内容。
- [x] 更换/取消只影响之后发起的生图；已保存图像、在途请求和已付费待发布回执不失效、不自动重绘，不重新编排或改变摘要。任务身份及既有版本/重试契约保持。
- [x] 读写按服务端确认的故事所属书与所有权处理；越权、已删除/未发布、越界页、无图、非法媒体或跨站写入被拒绝。删除星标源故事取消该星，取消旧图不得清掉后来选择的新图。参考快照不可用时付费前报错，可取消或重新选择。
- [x] 增量迁移只新增存储结构，旧故事/回执不变；typecheck、lint、完整单元/集成和匹配服务E2E通过。浏览器不可用时如实记录，只证明UI渲染/交互契约及服务行为，不宣称视觉或真实模型一致性验证。

不做多星、多人物档案、自动替用户选图、自动重绘、真实付费生图对比、桌面/Docker打包。跨画风也只有一颗书级星；参考只提供可见人物识别依据，选定画风继续生效。
