# 增加明确的画幅数审核，九篇真实回归

实测新版直接审《林黛玉初进贾府》旧40幅时，Codex仍把多数概括处理判为充分，只修两幅便以40幅通过；同参数完整重编的初步提纲也只有35幅。允许增删与保存coverage没有自动带来此前人工重编的补戏力度。

用户要求九篇都能复现同等关键戏，已明确“关键戏补齐，幅数允许有据浮动”。参考数为40→53、26→36、34→44、20→29、20→24、16→20、22→26、22→26、18→22，不能把它们作为编排输入或每篇固定配额。

- [ ] 保留原审核主体，在原事实/语言/构图/连续性/结语审核之前增加独立四步画幅数审核：当前数量应保留、增加、减少还是重分配，给出建议数量和基于原文关键戏/关系变化/反应停顿的理由；自动模式不能省略此结论。
- [ ] 画幅数需要调整时必须给出具体结构问题并进入已有增删/替换及全篇复核闭环；不能用同幅长旁白或事后状态冒充关键戏。建议数量不是新锁定目标，审核后仍可按有据修订变化。
- [ ] 原有提供方/推理设置、原文绑定与原全面审核保持；测试器隔离保存两阶段回执和每轮分镜，重启复用成功调用，非法输出/无变化/超限停止。只测试v1→v2，不更改正式书架或制作队列，不生图；不新增原文提取步骤。
- [ ] 用同一份通用规则和真实Codex对九篇旧稿进行隔离回归，补戏清单和人工稿只供事后验收；逐篇保存实际幅数、原文依据、回执、修订历史与独立核对结果，不向生产模型泄漏参考数字或人工清单。
- [ ] 九篇分别通过此前补戏任务的逐项核对：入府的观察/称呼/告诫/赠字/夜间余波，葬花的诗意层次与悲意扩展，怄气的双方相反期待与剪穗回应，话香的耗子故事和三人尾声，诉肺腑的误认与掩饰，赐礼的愿赠/止誓/避嫌与失神，药方的夸药/作证/回敬与次日问答，参禅的无言/读稿/主意与问难，湘云打趣的独泣/亲疏先后/无言与三人交锋。不得用模型自称通过替代逐项证据。
- [ ] 受控回归、适当完整本地检查和独立CR/VR通过；真实九篇只运行文字流程，原版、已完成53等参考稿和媒体保持，不打包或发布。

范围是通用编排/审核能力与真实回归证据。不得增加故事名特判、把人工稿复制成系统输出、喂入目标幅数凑结果，或只测试第一篇便声称九篇完成。

用户后续明确收窄：先保留原审核提示，加入画幅数审核；原文独立拆戏仅保留为实验，不接入正式流程。九篇关键戏覆盖与幅数可浮动的最终验收保持。

用户最终范围澄清：不更新书架，只测试故事分镜v1能否改进到测试v2。本次用真实共用生成器的两阶段离线测试器验收九篇，不迁移正式制作队列/检查点/UI，也不声称默认制作流程已经上线。
