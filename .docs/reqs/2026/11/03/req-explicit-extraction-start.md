# 点击按钮才开始提取

用户进入窗口是为了先核对原文、主题与标题方式，不应在确认前启动模型读取。

- [x] 未直接选定故事的新建任务和重选草稿以未查找状态保存，候选为空；打开、轮询、请求观看、关闭重开或服务重启均不自动提取。
- [x] 自动标题/输入标题只是本地条件；只有明确点击提取按钮才开始新轮次，沿用现有search命令及重放、并发围栏。
- [x] 点击开始后按既有流程逐段发现故事，主题和原文范围不变；既有已启动任务与直接选定source的准备流程保持兼容。
- [x] 新建入口按钮准确表示进入提取窗口，初始窗口与书架显示等待开始，不误称正在查找或已找到零篇。
- [x] 重选草稿开始前不提取，不改变父故事；开始和取消的隔离、暂停与确认制作边界继续有效。
- [x] 生产API、客户端观察、重启与界面验证证明开始前推理调用数为零，点击后能返回故事；标题/主题/范围组合仍可用。

不增加新模式、数据库迁移或检索加速。已获授权、仍在运行的旧搜索不强制取消。
