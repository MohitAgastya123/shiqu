# 在提取窗口修改标题

标题应在看得见提取进度和候选的地方输入、修改，并直接用于新的提取。新建条件窗口保留书籍、主题与原文范围。主操作按钮上方需要明确留白。

- [ ] 新建条件窗口不再重复输入目标标题；“开始发现故事”主按钮上方有24px留白，原文范围按钮及摘要中的“整本书”改为“自动”。
- [ ] 未选中故事的提取窗口提供可选标题输入和显式提取按钮；填写后定向提取，清空后自动发现，主题与范围不变。选择已有单篇原文段落也要先进入提取窗口，能继续组合标题。
- [ ] 修改标题提交会保存新意图、开始新轮次并清理旧候选；尚未提交的输入不触发提取。运行中的旧结果不能混进新候选。
- [ ] 重新打开保留已提交标题；重复请求不重复启动，过时的选择/查询不能覆盖新状态。
- [ ] 已有故事的重选草稿复用同一输入与提取流程；查找或取消不更改原版本，确认选择才替换。
- [ ] 已确认制作的版本不能直接重置查询；已有准备步骤的锁和暂停/停止状态不能被查询命令绕过。
- [ ] API、并发晚到、重启、重选与浏览器验证通过，按钮间距和窄屏布局可检查。

本次不增加主题/原文范围的在线修改、不增加向量库或候选章节加速。已准备故事窗口内的候选切换保留现有逻辑；更换提取目标使用未选中状态的新建或重选草稿。
