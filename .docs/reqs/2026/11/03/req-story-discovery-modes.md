# 选题模式与主题

标题、主题、原文范围是三个独立可选条件，不再要求用户先选择提取模式。原文范围使用书库章节或已有独立故事段落，不增加粘贴原文功能。

- [ ] 新建入口分别提供可选故事标题、可选主题、可选原文范围。三者任意单项、两项、三项及全部留空都可创建；留空标题自动发现。
- [ ] 原文范围可选多个章节或一个已有独立故事段落；未限定时阅读本书。标题与独立故事段落也能组合，范围不足时不扩到未选原文。
- [ ] 自动发现按原文识别独立完整事件，再按主题筛选，不因选多章强制先找一个总故事。
- [ ] 标题模式保存目标标题，只返回该故事的完整原文范围；范围不足或不存在时明确提示，不退回局部事件、其他故事或凭记忆补全。
- [ ] 标题模式中主题保留到制作阶段，用于叙述重点，不能过滤掉或改变指定故事；默认不限定主题。
- [ ] 模式、目标和范围经重开、重试后保持；标题查询、自动发现及既有缓存互不串用，旧任务仍可继续。
- [ ] 通过生产流程验证“三败高俅”覆盖第78—80回；覆盖自动发现加主题、缺少章节、缓存与输入验证，并完成界面检查。

不改模型配置、部署、导出或书架数据。非本地书籍保留现有按主题发现能力；按标题提取只开放给有可核对原文的本地书库。
