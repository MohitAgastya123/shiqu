# 可供 Codex 使用的完整无服务 CLI、书库恢复与发布回归

## 问题与决策

作品与已付费结果依赖本地数据库和媒体的一致保存。目前升级备份依赖手工复制，桌面错误缺少可携带的诊断，浏览器生命周期回归没有进入发布检查。本轮把这些能力接入真实 CLI、开库和服务生命周期；保持本地优先，不增加云服务。

用户于本轮 `!!` 扩充目标：CLI 是与桌面/网页并列的完整操作入口，供 Codex 直接发现和调用。无子命令时保留现有 npx 启动服务；有子命令时不监听端口、不启动桌面或前端，直接操作同一生产业务、数据库和媒体。

## 验收

- [ ] R1：CLI 可在停服后创建完整书库备份，数据库使用一致快照，媒体/缓存原字节保存，清单含大小与 SHA-256；验证能拒绝缺文件、篡改、额外文件、符号链接及非法相对路径。
- [ ] R2：恢复先验证备份，只发布到不存在的新目录，失败不留下可误用的半成品，不覆盖任何已有书库；恢复后检查数据库、故事/版本/任务、媒体及阅读进度。恢复操作及显式只读验证不产生模型调用；之后正常启动保留既有控制和后台制作语义。
- [ ] R3：已有书库存在待执行迁移时，任何迁移写入之前自动创建并验证一次升级前备份。备份失败则不开启升级；新库与无迁移重开不备份。备份不删除旧备份，能恢复到对应旧结构。
- [ ] R4：维护备份必须拒绝使用中的书库；开发、CLI 和桌面使用同一服务锁。维护操作不配置提供方、不启动服务、不调用模型、不读取真实凭据。
- [ ] R5：CLI/桌面/开发服务保留容量有界、私有权限的安全诊断事件，包括启动/停止、已知任务错误、请求错误。只允许事件名、时间、任务ID、受限错误码和计数，不记录密钥、正文、提示词、原始异常或提供方响应。
- [ ] R6：CLI 可导出脱敏诊断 JSON，包含应用/运行时版本、数据库检查与任务计数及近期安全事件；不导出书名、原文、提示词、路径、凭据和模型原始回执。损坏/丢失的库仍能给出受限诊断结果。
- [ ] R7：本地发布检查在同一待发布提交中执行现有 E2E，失败阻止发布；不把完整回归重复放回平台构建，不运行打包或真实AI作为普通验证。
- [ ] R8：文档给出备份、验证、恢复、诊断、升级回退步骤和凭据边界；单元/集成、类型、lint、匹配 E2E 验证通过，所有验证仅使用隔离数据。
- [ ] R9：`shiqu` 无子命令仍按现有规则启动浏览器服务；子命令支持 `init`、状态、书籍/主题/画风目录、故事列表/读取/创建/选题/确认/运行/编辑/改名/版本/暂停/恢复/重试/删除/收藏/参考图，以及预览、导出和书库维护。全部通过本地生产业务执行，不依赖 HTTP 监听、桌面或浏览器。
- [ ] R10：`help --json` 提供版本化命令目录、参数、输入示例和执行影响；子命令 stdout 为单一版本化 JSON 结果，日志走 stderr，错误包含稳定 code/message、非零退出码。支持 JSON 文件或 stdin 输入，以及显式 requestId/CAS/fault 身份；不得把密钥写入输出。
- [ ] R11：非 `run` 命令只执行用户指定动作，不启动后台制作。`run <id>` 只运行指定当前版本，不能调用其他 active/background 故事；选题有明确有限结果与查看需求生命周期。支持准备完成、审核完成、整篇完成的停止边界、超时和中断，保留已保存回执，旧版/暂停/失败仍服从生产状态机。
- [ ] R12：编辑、重选、故障恢复、审修历史与提示词、制作/验收要求和署名使用原正式校验及版本/幂等规则；为持久化与观察业务动作提供发现性命令或通用进程内 API 调用入口。普通 api 只允许白名单非推理 reader 动作，直接建议/画风推荐/历史生成/advance 等接口以稳定 EXECUTION_REQUIRED 错误拒绝，生成统一由显式生产 run 推进；白名单外的新路由默认拒绝。写入与执行分开，修改/确认本身不偷偷调用生成。
- [ ] R13：离线预览输出可直接打开的静态 HTML，图片为本地已保存数据，文本转义，不嵌入密钥或执行脚本；不启动浏览器/HTTP。
- [ ] R14：无浏览器导出 JSON、Markdown、ZIP、PDF 和 PNG；复用应用的布局/绘图、水印、署名、文件名、序列化、哈希与 XMP 规则。通过注入画布/图片读写适配器共享实现，不伪造全局 DOM、不维护第二套导出规则。原图不被改写；不同编码器不承诺字节相同。
- [ ] R15：完整图片导出必须选择当前版本且全部画幅可读，不能静默降用旧版。公开 ZIP 不含内部提示词；内部 ZIP 明确选择。未署名需显式 `--allow-unsigned`。已导出的 WebP 转公开格式继续原字节保留。输出为显式路径，不自动提交或发布作品。
- [ ] R16：无服务 CLI 复用已保存服务配置或显式环境；读库/预览/导出不检查云端、不询问密钥，init 可建立未配置的本地库。生成命令明确检查可用服务；无交互时给出配置下一步，不静默降级或换计费方式。
- [ ] R17：隔离数据与受控提供方完成整条 CLI 初始化→选题→准备→确认→审核制作→编辑/版本→预览/导出→备份/恢复；验证零监听端口、无前端进程、请求幂等、暂停/故障边界、目标隔离和 npm 包中的原生导出依赖可用。真实 AI 与跨平台结果不由受控测试冒充。

## 边界

- [ ] R19：用户明确要求全局技能安装：`skill install --scope global` 复制到当前用户 `~/.agents/skills/shiqu/SKILL.md`，无需项目；默认仍要求显式范围。不在实现/测试时安装到真实 home，沿用不覆盖不同内容、无书库/推理副作用与拒绝符号链接的约束。

- [ ] R18：npm 包随版本携带 `skills/shiqu/SKILL.md`；`skill show` 可直接读取完整正文，`skill install --scope project` 复制到当前目录 `.agents/skills/shiqu/`。安装不依赖 npx 缓存持久性，不覆盖已有不同技能，不初始化数据库、不联网/生成/监听。技能描述实际 CLI 流程和生产边界，详细命令通过当前版本 help 查询。

备份是私有目录快照，不是公开作品 ZIP；不包含书库之外的 desktop.sqlite 凭据，不自动恢复提供方设置。恢复不自动切换用户默认书库、不自动升级备份、不发起制作。已有控制/历史/付费回执原样保存，正常启动沿用既有状态机。CLI 是本轮操作入口，不增加桌面页面、云备份、定时备份、加密存储、自动清理策略、桌面/Docker安装包或版本发布。允许构建并验证 npm CLI 本地产物，禁止向注册表发布。自动备份空间不足时停止升级，保留用户原库。
