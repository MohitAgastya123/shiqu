# 拾趣技能升级

安装副本会与 npm CLI 漂移。使用技能时应能发现正式发布的新版，并按用户偏好更新，保护定制内容。

- [ ] R1：安装保存版本、内容哈希和默认关闭的自动更新偏好；旧版副本仅内容等于当前包时可认领。
- [ ] R2：check 自动发现项目祖先目录或全局安装，查询 npm latest，24 小时缓存；离线或远端异常返回可读状态，不阻止原任务，不污染书库。
- [ ] R3：check 输出固定版本更新命令及是否允许自动执行；开启/关闭偏好须显式操作；本地修改禁止自动更新。
- [ ] R4：update 只使用运行中 CLI 自带技能，拒绝降级、未知来源副本、符号链接及本地改动；默认提示而非后台下载执行。
- [ ] R5：SKILL 指导检查、仅在已启用自动更新且副本完整时执行配套版本更新，并重新读取技能/help；README 和指南说明限制及自然语言示例。

不新增后台服务、包执行器、GitHub main 更新渠道、数据库迁移或远程发布。不自动更改用户实际全局安装。旧副本内容不同需人工合并；不增加 force 覆盖。
