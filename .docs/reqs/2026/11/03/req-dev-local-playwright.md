# 开发数据库上的故事流程 E2E

- [x] `pnpm dev local` 使用 checkout 的 `.data/dev-local`，不跟随桌面书库或.env中的生产数据目录；原 `pnpm dev` 行为保留。
- [x] 提供可重复运行的Playwright命令，真实Vite、生产HTTP/API/队列/SQLite/媒体，开发测试库位于`.data/e2e`；不加载真实凭据或调用外部推理。
- [x] 浏览器完成新建、手动开始提取、选定、准备、修改草稿、确认制作、完成阅读，刷新验证保存及确认前零绘图。
- [x] 浏览器覆盖已生成故事的改名、制作要求/验收/画风/叙事/分镜/结语编辑、草稿取消与提交、历史版本和图片复用；无法执行的路径如实记缺陷。
- [x] 浏览器覆盖暂停/恢复、失败后只读观察与显式重试、重选取消和提交、单家族单卡片；API补充停止/重放/过期命令/重启等竞态规则，不冒充UI验证。
- [x] 保留每次运行证据、截图、Playwright trace、实际状态转换与数据位置；报告覆盖和未验证范围，更新状态机文档的手动提取入口。

限制：不触碰真实书库，不打包，不推送。受控模型回执仅证明流程，不证明真实AI内容质量。发现产品缺陷先留证据报告；本请求授权开发入口及测试基础设施，不包括相邻产品重构。
