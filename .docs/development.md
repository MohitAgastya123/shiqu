## Runtime and dependencies

Use Node **24.22.1** from `.nvmrc` and pnpm **11.25.0** from `package.json`.

```bash
nvm install
nvm use
corepack enable pnpm
pnpm install --frozen-lockfile
pnpm dev
```

The React/Vite reader normally serves port 3000 and proxies the Node API on port 3002. The backend uses Node's built-in SQLite and local media files; no separate database service is needed.

Use an isolated library for development:

```bash
SHIQU_DATA_DIR=/tmp/shiqu-development SHIQU_AI_PROVIDER=readonly pnpm dev
```

`pnpm dev local` isolates the library under `.data/dev-local`, but generation configuration still comes from shared settings. Explicit environment variables override only the current process. Development does not automatically load the project's `.env`. Never put credentials in `VITE_` variables. Ordinary `pnpm dev` can use the saved personal library, so specify an isolated directory before testing writes.

Use `SHIQU_API_PORT=3003 pnpm dev --port 3001` for another pair of ports. Stop the process before changing dependencies or clearing its Vite cache.

## Desktop preview

```bash
SHIQU_DATA_DIR=/tmp/shiqu-development VITE_DESKTOP_READER_URL=http://127.0.0.1:3000 pnpm desktop:preview
```

Open port 1420 in the in-app browser. Preview uses the real read-only library summary and cannot control native services or credentials. Use this for normal desktop UI work. Prepare, build or package the native application only when explicitly requested.

## Production architecture

`server/app.ts` opens the library through `ensureLibraryReady()`, creates local book access and the selected generation provider, and attaches the durable production coordinator. The reader API and direct CLI commands use that same core. `lib/reader-engine.ts` advances a saved story by one checkpoint, and `server/reader-production.ts` schedules search, text, image and local publication jobs with dependencies and leases.

The creation sequence is discovery, source preparation, confirmation, storyboard, title/ending, review, targeted repair/recheck, then illustration. Automatic stories use 1–80 frames, with storyboard batches of up to 20. Image generation establishes its first reference before parallel later frames. Saved results survive interruption; explicit recovery identifies the current fault and command, so a refresh cannot authorize duplicate paid work.

## English production and source translation

English is the product language. Shared English prompts request English discovery descriptions, summaries, story titles, captions, character settings, review explanations and endings. Schema limits accommodate English prose.

The pinned Chinese corpus remains immutable provenance evidence. During explicit preparation, `reader-source-english.ts` translates complete passages and chapter context in bounded chunks, saving each result before continuing. The same provider and production locks are used; translations are not generated by reading GET endpoints. Source views and new exports use the complete saved English representation. Interrupted translations resume at the next missing chunk, and partial or untranslated content is never substituted as English reading text.

Machine identifiers, migration SQL, original source hashes, historical prompt recognition and collection ZIP entry names remain stable. Display labels and generated prose are English. Existing user-owned stories are not silently regenerated.

## Verification

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm exec playwright install chromium --only-shell
pnpm test:e2e --gate=release
```

Tests use isolated libraries/settings and controlled provider responses. Do not use real credentials or the user's library for migration or generation tests. Focused English coverage lives in `tests/english-app.test.mjs`, `tests/english-ui.test.mjs` and `tests/english-reading.playwright.e2e.mjs`.

For maintenance command help, use `pnpm cli help --json` or `pnpm library:maintain --help`. Upgrades require a verified whole-library safety backup. Never restore a backup over an active library. Source changes do not authorize publishing or distributing a new installer.
