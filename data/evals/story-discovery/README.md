# 离线故事发现评测

运行 `pnpm eval:discovery`，或用 `pnpm eval:discovery --json` 获取 JSON。默认只读取本地标注与回执，不加载提供商、不联网、不产生费用。

`annotations.json` 是 agent 起草、尚待用户确认的40组主题判断与3章完整边界清单；原文、版本和定位可核对。`controlled.json` 是合成受控回执，用于验证评分工具，**不是任何真实模型的录制或准确度基线**。不能据此选择模型或宣称提速。

`--dataset` / `--receipts` 可选择其他本地文件。输入哈希、标注版本、语义契约必须一致才能比较；`--model` / `--effort` 没有对应录制时显示不可比较。真实录制须另行授权，本工具没有隐式在线模式。

精确率分母是判为yes的条目，端到端召回率分母是全部标注正例；未判断正例损失召回，覆盖率单列。边界按原文单元一对一精确配对，另列漏提、重复、合并/拆分和缺首尾的定位诊断；诊断可重叠，不代表因果完整性的语义结论。
